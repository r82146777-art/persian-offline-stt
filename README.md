# تایپ صوتی فارسی آفلاین (بدون گوگل)

اپلیکیشن اندروید برای **تبدیل گفتار فارسی به متن به‌صورت کاملاً آفلاین** با موتور متن‌باز **Vosk**.

- **بدون Google / Gboard / Speech Services**
- مدل: [`vosk-model-small-fa-0.42`](https://alphacephei.com/vosk/models/vosk-model-small-fa-0.42.zip) (~۵۱ مگ، Apache 2.0)
- بار اول مدل دانلود و در حافظه داخلی اپ ذخیره می‌شود؛ بعد از آن **بدون اینترنت** کار می‌کند
- دکمه میکروفون → صحبت → متن فارسی → کپی برای چسباندن در هر برنامه

## دانلود APK

از صفحهٔ **Releases** همین ریپازیتوری آخرین APK را بگیرید:

**https://github.com/r82146777-art/persian-offline-stt/releases**

(بعد از اتمام GitHub Actions، فایل APK در Release قرار می‌گیرد.)

## ساخت دستی

```bash
./gradlew assembleDebug
# خروجی: app/build/outputs/apk/debug/app-debug.apk
```

## نحوه استفاده

1. APK را نصب کنید  
2. مجوز میکروفون را بدهید  
3. بار اول با وای‌فای مدل فارسی را دانلود کنید (~۵۱ مگ)  
4. دکمه **تایپ صوتی** را بزنید و صحبت کنید  
5. **کپی متن** را بزنید و در واتساپ / پیام‌ها / هر جا بچسبانید  

## نکته درباره کیبورد سیستم

این اپ یک **برنامه مستقل** است (نه جایگزین Gboard به‌عنوان Input Method سیستمی).  
متن را کپی می‌کنید و در برنامه مقصد می‌چسبانید.  
جایگذاری به‌عنوان کیبورد سیستم نیاز به IME جداگانه دارد.
